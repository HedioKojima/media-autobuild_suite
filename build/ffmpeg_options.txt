# FFmpeg options for an mpv-only build.
# External libraries follow mpv-winbuild (HedioKojima, branch "rm"):
#   packages/CMakeLists.txt -> xz, uchardet, zlib, lcms2, libiconv, luajit,
#   fribidi, brotli, freetype2, harfbuzz, libunibreak, libass, xxhash, dav1d,
#   libarchive, highway, libjxl, libplacebo, ffmpeg, mpv
# Only what FFmpeg itself has to link against is listed here; luajit / libass /
# libplacebo / shaderc / spirv-cross are consumed by mpv directly, MABS builds
# them automatically because mpv is enabled.
#
# Keep FFmpeg's native decoders/muxers/filters complete: this is a player, so
# every container/codec FFmpeg knows must stay available. What is trimmed is
# only the *external* codec libraries nobody needs for playback.

# Platform / I/O, needed for http(s), zip, subtitles, archive demuxing
--disable-autodetect
--disable-debug
--enable-gpl
--enable-zlib
--enable-bzlib
--enable-lzma
--enable-iconv
--enable-schannel

# Windows hardware decoding: d3d11va + dxva2 cover Intel/AMD/NVIDIA
--enable-d3d11va
--enable-dxva2
--enable-mediafoundation
--enable-w32threads

# Codec / colour / subtitle libraries that mpv also uses
--enable-libdav1d
--enable-libjxl
--enable-lcms2
--enable-libass
--enable-libfreetype
--enable-libfribidi
--enable-libharfbuzz
